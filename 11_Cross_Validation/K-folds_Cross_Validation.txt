1.Cross-validation:
 Cross-validation is not just for checking how good one algorithm is — it also helps you compare multiple 
 algorithms fairly so you can pick the best one for your data.

2. The Most Common Type: K-Fold Cross-Validation
 Here’s how it works step by step:
   - Split your dataset into k equal parts (called "folds").
   - For each of the k iterations:
   - Use 1 fold as the test set.
   - Use the remaining k−1 folds as the training set.
   - Train and test the model k times.
   - Average the results (accuracy, error, etc.) to get the final performance.

 -> Example with 5-Fold Cross-Validation: suppose you have 100 data points.
    .You divide them into 5 parts: Fold1, Fold2, Fold3, Fold4, Fold5
    .Then run the model 5 times like this:
 | Iteration | Train On                      | Test On |
 | --------- | ----------------------------- | ------- |
 | 1         | Fold2 + Fold3 + Fold4 + Fold5 | Fold1   |
 | 2         | Fold1 + Fold3 + Fold4 + Fold5 | Fold2   |
 | 3         | Fold1 + Fold2 + Fold4 + Fold5 | Fold3   |
 | 4         | Fold1 + Fold2 + Fold3 + Fold5 | Fold4   |
 | 5         | Fold1 + Fold2 + Fold3 + Fold4 | Fold5   |

    .if we applied multiple algorithms of classification in each fold, this methode give the accuracy of each one, 
    and the most high one is the best algo

3. KFold vs StratifiedKFold — What’s the Difference?
 Both are used for cross-validation, but the key difference is how they split the data — especially important in 
 classification problems.

 KFold: Basic Split
   - Splits the data randomly into k folds.
   - Does not consider class distribution.
   - Some folds might have more of one class than another → this causes bias in training/testing.
 StratifiedKFold: Smarter Split
   - Splits the data while preserving the percentage of samples for each class.
   - Ensures each fold has the same class ratio as the full dataset.
   - Much better for classification problems, especially when the classes are imbalanced.

 -> Example:
    Suppose you have 10 samples:8 of class A, 2 of class B
    - Using KFold(n_splits=2):
      Might result in:
        . Fold 1: 7 × A, 0 × B → bad
        . Fold 2: 1 × A, 2 × B → worse
        
    - Using StratifiedKFold(n_splits=2):
      Will result in:
        . Fold 1: 4 × A, 1 × B
        . Fold 2: 4 × A, 1 × B
    → Balanced!
